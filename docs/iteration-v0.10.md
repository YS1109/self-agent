# 0.10 自托管网关与移动 H5 · 实施切片

状态：主程序/CLI/桌面与独立 H5 已接线，本地冻结联合门禁与独立源码审查通过；开发分支发布与精确 CI 单列，不代表真实公网或安装发布。

## 已确认方向

- 独立 Rust 网关放在用户自己的 nginx HTTPS 后；daemon 只建立经过认证的出站 WSS，原本机管理端口仍绑定 `127.0.0.1`。
- 网关仅保存设备目录/认证撤销资料及有界的在线请求，不保存任务数据库、不缓存离线待执行命令。任务、输入回执、权限和事件仍以 daemon SQLite 为准。
- 设备连接凭据与浏览器会话分离。浏览器不取得本机 daemon 管理令牌；本机所有者逐次确认配对身份、会话范围、动作权限、任务限制与期限。
- 首版浏览器会话仅保存在网关内存。页面刷新/网络重连可在同一有效 cookie 下恢复；网关重启后必须重新配对，不声称持久登录。
- 手机窄屏以会话为中心，简体中文灰蓝主题；支持查看、输入、进度、取消、回答问题。不能远程批准执行授权、管理模型/MCP/系统凭据或解除清理隔离。
- 产物限于真实持久任务结果、命令证据和观察 diff 的有界纯文本资源；使用不透明资源 ID，不提供工作区任意路径或二进制下载。

## 安全及失败合同

- 离线前拒绝为 `device_offline`；请求可能已发送后断线/超时为 `outcome_unknown`。客户端只读取原 `command_id` 回执，不自动生成新命令或重发执行。
- 一次性配对码有固定期限和容量；只有已签发码可生成待确认记录，不为无凭据陌生输入保存无限身份。确认与请求权限检查处于可信事务。
- 每次读取/写入重新检查设备、principal、绑定修订、会话和资源权限；撤销关闭活动流并拒绝后续发送。任务侧也检查撤权，不以网关先前通过认证替代本机权限。
- Cookie 使用 HttpOnly、Secure、SameSite=Strict、host-only；写请求校验 CSRF 和精确 Origin，不开放 CORS。仅显式本地 fixture 模式允许 HTTP loopback 测试 cookie。
- 请求/帧、并发、连接、待确认会话和慢客户端均有硬上限。心跳间隔小于 nginx 空闲超时；不把 DB 等待放入 WS 心跳循环。
- nginx API 无缓存、SSE 无缓冲、命令不重试上游；不记录请求正文、cookie 或认证头。实际 TLS 证书、域名、部署及公网开放仍由用户另行操作。

## 验收矩阵（实际状态见 acceptance-v0.10.md）

| 场景 | 必须证明 |
| --- | --- |
| 设备与浏览器凭据分离 | cookie 不可用于 device WS，设备 key 不可用于浏览器/本机 owner API |
| 配对与授权 | 过期/重复/不同 principal 兑换拒绝，本机明确确认前无任务权；默认动作拒绝 |
| CSRF / Origin | 跨源、缺失/错误 CSRF、伪造 source/owner 字段拒绝；安全 cookie/no-store 真实响应 |
| 幂等与未知结果 | 断线后原命令只执行一次；回执同事务，离线不排队，重连不执行旧命令 |
| 会话/资源隔离 | 不可读取其他会话事件/任务/diff/产物；每次读取检查权限和撤销 |
| 游标恢复 | 持久 daemon 游标、重复事件不重复拼接、失效游标触发权威快照 |
| 慢客户端与断连 | 限额生效、心跳不断、慢流被关闭而任务继续；撤权断开活动流 |
| 生命周期 | daemon/网关重启不重放；网关重启 cookie 失效并明确要求重新配对 |
| H5 | 刷新、重连、重复点击、关闭/切换会话、未知提交与只读恢复，不丢失未知事实 |
| 发布 | 本地真实多进程夹具、独立审查、精确树/CI；真实公网/TLS/移动网络另列未验证 |

协议细节随代码写入 [protocol-v11.md](protocol-v11.md)，不得沿用 QQ 协议作为网关权限代理。

实际门禁和未运行边界单列于 [acceptance-v0.10.md](acceptance-v0.10.md)，不以本规划中的验收目标代替证据。
