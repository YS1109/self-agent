# Self Agent 0.9：官方 QQ 通讯入口

日期：2026-10-28。状态：本机接口、Store 与连接/投递监督器已接线，本地联合验收和独立审查已通过，精确提交 CI 单独跟踪；本文不是外部平台实测或部署记录。用户已选择官方 QQ 机器人。当前开发和验收仅使用本地 HTTP/WebSocket、模型及凭据夹具，不连接真实 QQ、不发送真实消息、不登记真实凭据。

## 最小完整范围

1. daemon 通过官方出站 WebSocket 接收 C2C 消息与群内 @ 事件，完成访问令牌刷新、心跳、恢复、重连和有界错误处理。平台授予的权限与本应用授权分别检查，选择 intents 不等于平台已批准。
2. 本机所有者签发短时一次性配对码；远端提交后仍须在本机核对身份、具体对话和权限再确认；确认后有覆盖 30 秒平台时差的安全接收窗口，旧消息不会在之后自动执行。OpenID 按 AppID 和事件上下文解释，群管理员不自动拥有本地权限。
3. 为每个绑定配置会话/项目范围和明确操作权限；列出、创建、选择、运行、查询、取消、补充、继续，以及受限显式编排共用现有后台指令，不代理本机管理 bearer，不透传任意 HTTP 或 JSON 指令。回答问题与批准动作分离，QQ 不提供本机动作审批。
4. 输入持久去重后才能推进 QQ 序列；来源路由、绑定修订、被动回复 message ID 和序号固定保存。切换会话不改变旧任务回复目标。
5. 真实 HTTP 投递在 SQLite 锁外执行；接受确认和完成通知分开，结果未知不自动重发，重启保留 unknown。撤销阻止新指令及尚未发送的通知，不能承诺撤回已在途的消息。
6. 桌面/HTTP/CLI 可以管理配置、查看绑定/连接/投递状态、明确撤销。配置成功、连接成功、收到事件、任务成功和投递成功是不同状态。

## 严格边界

- 官方地址固定为 `https://api.bot.qq.com`；本地夹具地址只能在明确测试模式下指向 loopback。生产不接受任意地址、重定向或远端指定凭据目的地。
- Secret 使用独立 purpose/配置身份绑定的系统凭据引用；不存明文数据库、不从其他服务借密钥、不在日志/快照中暴露。已接入独立 QQ 凭据意图与现有系统凭据适配器；目前仅用内存凭据夹具验证，未登记真实系统凭据。
- QQ 公开文档对 C2C 被动回复时效存在不一致，默认采用保守的 5 分钟上限并保留可收紧设置；不将它声明为平台保证。群消息不做逐 token 输出，回复次数有界。长任务可能超过被动回复窗口，完成结果继续保存在本机；用户可发新消息主动查询。
- 不使用主动推送作为到期、限流或投递失败的自动后备方式；本轮不实现主动消息、Webhook 或频道消息。
- 远端不可修改模型服务、凭据、MCP/Skills、全局/角色权限、项目路径、清理隔离状态或配对授权；模型输出不能授予远端身份权限。
- 全局快照、原始日志、本地路径、完整工具输出和任意文件下载不向 QQ 暴露。群聊输出需要所有者单独启用并按群受众限制内容。

## 已接线与待验收的区别

- 已实现本机 owner HTTP 配置/授权/凭据接口、App 中 QQ 管理入口与 CLI；QQ 凭据与模型服务、MCP 凭据作用域互不通用。页面中的“存在绑定”、系统存储可读、平台鉴权与连接状态分别呈现。
- 已实现 daemon 单配置修订监督器、入站/命令/投递分离循环、SQLite 原子游标与指令、任务/编排来源检查及终态通知桥接。同步 SQLite 工作在阻塞线程执行，不持锁等待网络。
- 已通过独立模块、实际 Store/API、真实 daemon + CLI + 本地 HTTP/WebSocket/模型联合夹具以及工作树全套 Rust/前端检查；具体批次见 [0.9 验收记录](acceptance-v0.9.md)。其余兼容门禁、独立审查及精确提交 CI 在该记录未确认前均不算通过。
- 没有真实 QQ 收发、真实模型调用、真实系统凭据登记、完整原生 GUI 或三平台运行验收；当前不得发布为“真实平台已验证”。

## 模拟验收矩阵

| 范围 | 必须验证 |
| --- | --- |
| 鉴权与传输 | expiry 数字/字符串、并发刷新、401、重定向拒绝、坏 JSON/超限/超时、心跳丢失、resume、无效 session、重复事件、重启 |
| 配对与权限 | 过期/重用/并发兑换、待本机确认、错误 AppID/用户/群、跨会话访问、默认拒绝、撤销与旧修订、不会变成本机 owner |
| 输入与路由 | 重复 event/message 不重复任务、同 ID 冲突拒绝、原子接收与游标、每身份+对话选择隔离、切换后旧任务仍回原路由 |
| 投递 | 429 延后、5xx/断连/响应丢失 unknown、不自动重发、重启 sending→unknown、固定 msg_seq、被动窗口/次数耗尽、撤销前后发送栅栏 |
| 使用流程 | 本机配置/配对→QQ 接收确认→运行→忙时查询/取消→原路由结果；实际本地模型与 WebSocket/HTTP 夹具，不以模拟文字代替调用 |
| 兼容 | 旧数据库迁移保留历史、旧桌面/CLI/HTTP 测试、0.8 限制不放宽、三平台精确提交 CI |
